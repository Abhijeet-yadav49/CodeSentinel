03 / UNDER THE HOOD

Small tool. Real engineering.

CodeSentinel parses source into Python's AST and applies explicit, testable rules. It never executes the inspected code.

01

Parse

Convert source text into a syntax tree. Syntax errors are reported before rules run.

02

Inspect

Walk calls, assignments, exception handlers, and function defaults for known risky patterns.

03

Explain

Return rule IDs, severity, line numbers, snippets, and actionable remediation guidance.
